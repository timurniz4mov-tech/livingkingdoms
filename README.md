# Living Kingdoms — мод для Minecraft (Fabric 1.20.1)

Живой мир: путники и торговцы на дорогах, деревни и замки с лордами и королями, работа и деньги,
разбойники, войны между королевствами и миникарта с границами территорий.

## Сборка
1. Установите JDK 17 (или новее).
2. В папке проекта: `./gradlew build` (Windows: `gradlew.bat build`).
3. Готовый мод: `build/libs/livingkingdoms-0.1.0.jar`.
4. Положите его в `mods/` вместе с Fabric Loader 0.15+ и **Fabric API** для Minecraft 1.20.1.

Для запуска из IDE: откройте папку в IntelliJ IDEA, импортируйте как Gradle-проект, запустите задачу `runClient`.

## Что есть
- **Жители (NPC)**: работяга, слуга, шахтёр, фермер, строитель, стражник, воин, торговец (в деревне), странствующий торговец,
  путник, разбойник, лорд, король. У каждого свой скин и инструменты/броня от дерева/кожи до алмаза (уровень 0–3).
- **Деревни и замки** строятся сами при исследовании мира (по ячейкам 256×256 блоков), у каждого есть название, лорд/король и жители.
  Первый замок региона создаёт королевство; ближайшие деревни и замки входят в него.
- **Дороги** между соседними поселениями прокладываются, когда загружаются чанки рядом.
- **Путники и странствующие торговцы** появляются возле игрока, идут от поселения к поселению, отдыхают и идут дальше.
- **Разбойники**: грабят путников и торговцев; большая банда (6+) идёт на штурм деревни. Роняют монеты.
- **Войны**: короли объявляют войны по случайным причинам, воины идут в бой, рядом с игроком появляются отряды обеих сторон.
- **Деньги**: золотая монета. Работы игрока: `/civ job laborer|miner|farmer|builder|servant|guard|soldier|trader`.
- **Земля и лорды**: `/civ buyland` (300 монет) — купить землю у ближайшего короля и стать лордом.
- **Дом**: `/civ buyhouse` (40 монет). **Королевство**: работа `trader` + `/civ kingdom found <имя>` (1500 монет), затем `/civ war <королевство>` и `/civ peace`.
- **Миникарта** (правый верхний угол): рельеф, границы королевств цветом, города/замки. `M` — масштаб, `N` — вкл/выкл.

## Команды
`/civ info`, `/civ job <...>`, `/civ buyland`, `/civ buyhouse`, `/civ kingdom found|list`, `/civ war <имя>`, `/civ peace`
Для админа (оп): `/civ gen village|castle`, `/civ spawn <профессия> [0-3]`, `/civ randomwar`.

## Известные ограничения первой версии
- Вне загруженных чанков мир «замирает» (NPC двигаются только рядом с игроками).
- Войны не меняют владельцев поселений; строители-NPC пока не строят реальные здания.
- Звуки используются ванильные (свои .ogg можно добавить в `assets/livingkingdoms/sounds/`).
